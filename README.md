## ✨ وش يسوي البرنامج؟
- 📡 **يتابع البث لحظة بلحظة**: تعليقات، هدايا بصورها، لايكات، متابعات، مشاركات، وأكبر الداعمين
- 🔗 **يربط أي هدية بأي أداة** في اللعبة (مساعدة أو تخريب) من قائمة فيها صور كل هدايا تيك توك
- 🏅 **نقاط ومستويات دائمة** للمتابعين، مع ترتيب أسبوعي وشهري وألقاب من «مبتدئ» لين «ملك البث»
- 🧑‍🤝‍🧑 **33 شخصية 3D** — كل متابع له شكل ثابت وصورته فوق راسه
- 🛒 **متجر ألعاب** وتحديث تلقائي من داخل البرنامج
- 🧪 **وضع تجربة** تجرّب فيه كل شي بدون بث

## 🎮 الألعاب
| | اللعبة | الفكرة |
|---|---|---|
| 🎡 | **حروف** | حرف وتصنيف، واللي يغلط يموت بطريقة تضحك |
| 🏰 | **حصن الصمود** | احموا الحصن من الوحوش أو خرّبوا عليه |
| 🏁 | **سباق المتابعين** | اللايكات والهدايا تسرّعك للخط |
| 🪢 | **حرب الفريقين** | فريقين يسحبون الحبل بالهدايا |
| 👑 | **عرش أكبر داعم** | اجلس على العرش لين أحد يطيّحك |
| ❓ | **سؤال وجواب** | مسابقة ثقافية بالتعليقات |
| 🔀 | **رتّب الحروف** | أول واحد يرتب الكلمة يفوز |
| 💣 | **القنبلة** | مرّرها قبل ما تنفجر عندك |
| ⚔️ | **ساحة القتال** | آخر واحد يبقى بالساحة هو البطل |

## 📺 العرض في البث
افتح اللعبة من البرنامج، وفي **TikTok LIVE Studio** أضف «التقاط نافذة» أو مصدر «رابط». وفي **OBS** أضف Browser Source بنفس الرابط.
